# HDF
## HDF简介
- HDF
  - HDF（OpenHarmony Driver Foundation）驱动框架
  - 包括驱动加载、驱动服务管理和驱动消息机制
- HCS
    - HDF Configuration Source
    - 是HDF驱动框架的配置描述语言
    - 是为了实现配置代码与驱动代码解耦
- HC-GEN
    - HDF Configuration Generator
    - 是将配置文本转换为最终目标的工具
    - 转换结果
        - 在弱性能环境中，转换为配置树源码，驱动可直接调用C代码获取配置。
        - 在高性能环境中，转换为HCB(HDF Configuration B- inary)二进制文件，驱动可使用HDF框架提供的配置解析接口获取配置。

## HDF功能
### 驱动加载
- 按需加载
  - 在系统启动过程中默认加载
  - 或者在系统启动之后动态加载
- 按序加载
  - 在系统启动的过程中按照驱动的优先级进行加载

### 驱动服务管理
- 集中管理驱动服务
- 包括驱动服务的编写、绑定、获取或者订阅

### 驱动消息机制
- 支持用户态应用和内核态驱动之间相互发送消息

## 驱动开发步骤
- 驱动实现
  - 驱动业务代码
  - 驱动入口注册到HDF框架
- 驱动配置
  - 驱动设备描述（必选）
  - 驱动私有配置信息（可选）
