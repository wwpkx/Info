# Hyper-V
- 是 **微软面向企业和专业用户的免费虚拟化平台**，以 Type-1 架构、企业级功能和 Windows 原生集成见长
- Hyper-V 主要支持 `.vhd`（旧版）和 `.vhdx`（新版，推荐）
- 打开 “Hyper-V 管理器”，右键点击左侧主机名 → 选择 “新建”→“虚拟机”；
- 代数：选择 “第 2 代”（支持 UEFI 启动，性能更好，仅 64 位系统支持）
- 虚拟硬盘：创建新虚拟硬盘（VHDX 格式，建议 30GB+），或使用现有硬盘
- **注意**
	- **我的电脑好像只能运行第一代**

# 启用 Hyper-V 增强会话模式
- **仅支持 ​​第二代虚拟机​​（需使用 UEFI 固件）**
	- 我安装的是第一代虚拟机
- 可实现动态分辨率调整（类似 VMware 的自适应窗口）
- 还支持剪贴板共享、文件拖拽
```
# 确保 Ubuntu 已安装集成服务
# 安装 Hyper-V 优化内核和工具
sudo apt install -y linux-azure linux-tools-azure 

# 安装 xrdp 服务（增强会话依赖）
sudo apt install -y xrdp
sudo systemctl enable --now xrdp  # 启动并设置开机自启

# 在 Hyper-V 中启用增强会话
- 关闭 Ubuntu 虚拟机，右键虚拟机 → “设置” → “集成服务”，勾选 “增强会话模式”（若有）；
- 启动虚拟机，在 Hyper-V 窗口顶部点击 “视图” → “增强会话”（或按 Ctrl + Alt + P）；
- 首次连接会弹出分辨率配置窗口，选择需要的分辨率（如 1920x1080），点击 “连接”。
- 连接后，可通过 “视图”→“全屏” 进入全屏模式，或拖动窗口边缘自动调整分辨率（动态适配）。
```

# VirtualMachinePlatform vs Hyper-V

| 维度      | VirtualMachinePlatform（虚拟机平台） | Microsoft-Hyper-V（Hyper-V 平台） |
|---------|-------------------------------|-------------------------------|
| 功能定位    | 轻量级虚拟化底层组件，支持 WSL2 等轻量场景      | 完整虚拟化平台，支持创建 / 管理完整虚拟机        |
| 核心用途    | 支撑 WSL2 运行、轻量级容器              | 运行完整操作系统的虚拟机、企业级虚拟化           |
| WSL2 依赖 | 必须启用（WSL2 核心依赖）               | 不依赖（WSL2 可独立运行）               |
| 系统版本支持  | 所有 Windows 10/11 版本（包括家庭版）    | 仅专业版、企业版、教育版                  |
| 功能完整性   | 仅提供底层虚拟化支撑，无管理工具              | 提供完整的虚拟机管理功能（如快照、虚拟网络）        |
