# wsl2 安装
- 系统要求，Windows 10/11, `winver`
- 启用 Hyper-V 虚拟机平台 
	- 打开任务管理器，切换到 **性能** 选项卡，查看 “虚拟化” 是否显示为 “已启用”
- 启用 CPU虚拟化技术
	- 在 BIOS 中开启，通常名为`Intel VT-x`或`AMD-V`
- 更新 WSL2 内核， [微软官方 WSL2 内核更新包](https://wslstorestorage.blob.core.windows.net/wslblob/wsl_update_x64.msi)
- 设置 WSL2 为默认版本，`wsl --set-default-version 2`
- 安装linux
	- 安装位置：
	- 安装方式1
		- [WSL 发行版下载地址](https://learn.microsoft.com/zh-cn/windows/wsl/install-manual#downloading-distributions)
		- 通过命令行下载： `Invoke-WebRequest -Uri https://aka.ms/wslubuntu2204 -OutFile Ubuntu2204.appx -UseBasicParsing`
		- 直接安装
			- `Add-AppxPackage .\Ubuntu2204.appx `
		- 安装方式2
			- 通过wsl命令安装
- 迁移已安装的发行版 到d盘
	- 导出当前发行版
	- 注销原发行版
	- 重新导入到新路径

# 启用 “虚拟化技术”
```
# 通过 控制面板\程序\启用或关闭Windows功能，打开
Hyper-V
Windows虚拟机监控程序平台
适用于Linux的Windows子系统
虚拟机平台

# 通过命令行
# 启用 Hyper-V 虚拟化平台
dism.exe /online /enable-feature /featurename:Microsoft-Hyper-V /all /norestart
# 启用虚拟机平台
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
# 启用 WSL 子系统
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart

wsl --set-default-version 2  # 设置默认版本为 WSL2
Restart-Computer  # 重启生效
```

# 迁移已安装的发行版 到d盘	
```
wsl --export Ubuntu D:\wsl\Ubuntu-22.04.tar
wsl --unregister Ubuntu
wsl --import Ubuntu-22.04 D:\WSL\Ubuntu-22.04 D:\wsl\Ubuntu-22.04.tar --version 2
```

# WSL 2 的内核版本
```
# 在 WSL 内部查看
# 5.10.16.3-microsoft-standard-WSL2
uname -r 

# 在 Windows 终端查看
wsl -d Ubuntu-22.04 uname -r
```
# wsl 安装发行版
```
# 列出在线商店可安装的发行版
wsl -l -o
wsl --list --online

# 安装 WSL 及默认 Ubuntu 发行版
wsl --install
wsl --install -d Debian
```
# wsl 发行版
```
wsl   # 启动默认发行版
wsl -d Ubuntu-22.04      # 启动指定发行版

wsl --terminate Ubuntu-22.04  # 停止指定发行版
wsl --shutdown  # 关闭所有WSL实例

wsl -l -v # 查看已安装的发行版
wsl --set-default Ubuntu-22.04 # 设置默认发行版

# 永久删除指定发行版（数据丢失）
wsl --unregister Ubuntu-22.04
```

# 文件互操作
```
# 在 Linux 中访问 Windows 文件
# Windows 的磁盘挂载在/mnt/目录下
cd /mnt/d  # 访问Windows的D盘

# 在 Windows 中访问 Linux 文件
\\wsl$\Ubuntu-22.04\home\
```

# WSL 和 WSL 2
| 方法           | WSL 1 特征                               | WSL 2 特征                                          |
| ------------ | -------------------------------------- | ------------------------------------------------- |
| wsl -l -v 输出 | VERSION 列显示 1                          | VERSION 列显示 2                                     |
| 内核版本         | 标准 Linux 内核<br>`4.4.0-19041-Microsoft` | 含 WSL2 标识<br>`5.15.133.1-microsoft-standard-WSL2` |
| 系统要求         | Windows 10                             | Windows 10/11                                     |
| 虚拟化支持        | 无需开启                                   | 必须启用 Hyper-V 和 CPU 虚拟化                            |
| 功能完整性        | 有限（无 Docker、GPU 加速）                    | 完整（支持 Docker、GPU 加速）                              |
