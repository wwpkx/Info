# Snap
- 容器化封装​
	- Snap 应用自带运行环境，包含应用代码、依赖库和配置文件
- 沙盒安全机制​
- 跨平台兼容性​
	- 开发者一次打包即可覆盖多平台
	- 例如，同一版 Firefox Snap 包可在 Ubuntu 22.04 和 Fedora 38 上无缝运行

| **​特性​**​     | ​**​传统 APT​**​ | ​**​Snap​**​  |
| ------------- | -------------- | ------------- |
| ​**​依赖管理​**​  | 依赖系统库，易冲突      | 自包含依赖，零冲突     |
| ​**​更新机制​**​  | 手动更新，版本滞后      | 自动后台更新，实时同步   |
| ​**​安装包大小​**​ | 较小（共享系统库）      | 较大（含完整依赖）     |
| ​**​跨平台支持​**​ | 仅限 Debian 系    | 全主流 Linux 发行版 |
| ​**​版本控制​**​  | 单一版本           | 支持多版本共存与回滚    |

# Snap 的常用操作命令
```
# 基础操作
snap list               # 列出已安装的 Snap 包
snap find vlc           # 搜索应用
snap install vlc        # 安装应用
snap remove vlc         # 卸载应用

# 版本控制
snap refresh            # 更新所有 Snap 包
snap revert vlc         # 回滚到旧版本

# 权限管理
snap connections vlc    # 查看权限配置
snap connect vlc:camera # 授予摄像头权限
```
