# 虚拟机
## 虚拟化技术
- 虚拟机 Hypervisor
    - 共享硬件
    - 不同的虚拟机可以运行不同类型的操作系统
- 容器 Docker
    - 共享操作系统
    - 不同的容器都可以运行在**全新**的操作系统

## 虚拟机比较
- vmware，应用最广
- virtual box，使用已存在的虚拟机很麻烦
- mutipass
    - ubuntu 出品
    - 虚拟 ubuntu 很方便
- win
    - wsl
        - win 子程序
        - 天然支持linux UI程序，通过 wslg 技术，可以直接运行ui程序
    - hyper v
        - 和 vmware 一样
        - 可以设置ip 和 ssh

## 启用Hyper-V功能
- 控制面板 — 程序 — 启用或关闭Windows功能
- Hyper-V
- 适用于linux 的windows子系统
- 虚拟化平台
## wsl
- win11 启用 “虚拟化技术”
- 启用 `Intel VT-x`或`AMD-V`
- 更新 WSL2 内核
- 设置 WSL2 为默认版本，`wsl --set-default-version 2`
- 安装linux，默认安装到c盘
- 可以通过导出/导入，改变安装位置

## Hyper-V
- 主要支持 `.vhd`（旧版）和 `.vhdx`（新版，推荐）
- 打开 “Hyper-V 管理器”，右键点击左侧主机名 → 选择 “新建”→“虚拟机”
- 支持快照（检查点）
