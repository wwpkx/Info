# 电学基础
- 原子
	- 原子核
		- 质子Proton
			- 带⼀个单位的正电荷
			- 且质⼦数量决定着元素身份
		- 中子Neutron
			- 中⼦不带电
	- 电子Electron
		- 带⼀个单位的负电荷
		- 围绕原⼦核做⽆规则的运动
		- 质⼦数和电⼦数相等，原⼦呈电中性
		- 不同电荷之间互相吸引，相同电荷之间互相排斥
		- 电⼦层
			- **理论上**, 每层最多容纳电子数，$2n^2$
			- **最外层电⼦数为 8个时**，通常是较稳定的状态
			- 最外层的电⼦更容易脱离原⼦
- 电流
	- 大小：单位时间内通过导体横截⾯的电荷量
	- ⽅向：正电荷的流动的⽅向
	- 单位：安培(A)
	- 1A，1秒钟内有1库伦电荷通过了导体横截⾯
	- 1 库伦(C) =  $6.242*10^{18}$ 
- 电压
	- ⼜称电势差，是两点之间电势的差值
	- 单位：伏特( V )
	- 1V ：电场 对 1库伦(C) 电荷，做了 1焦⽿(J) 的功
- 电阻
	- 材料或元器件对电流流动的阻碍程度
	- 单位：欧姆（简称欧），符号是Ω
- 电功率
	- ⽤于衡量电流在单位时间内所做的功
	- 单位：瓦特（简称瓦），符号是W
	- 公式：P = UI
- 焦⽿定律
	- 单位：焦⽿(J)，简称焦
	- 公式：Q = $I^2Rt$
- 串联与并联
	- 串联电路是**分压**电路
	- 并联电路是**分流**电路，$R_总=\frac{R_1R_2}{R_1+R_2}$
