- 决定式
	- 描述⼀个物理量由什么**决定**
	- 仅通过**元器件的固有属性**（⻓度、横截⾯积、电阻率等），就能对物理量进⾏定量分析
- 定义式
	-  描述⼀个物理量**是什么**
	- 依赖于外部的测量条件（如电压、电流、时间等）来**定量分析**物理量
	- 或者说，可以通过**其他物理量**来测量或计算出来

# 电流（Electric Current）
决定式 $𝐼=\frac{𝑄}{𝑡}$​ 或微分形式 $𝐼=\frac{𝑑𝑞}{𝑑𝑡}$​，其中：
- 𝐼 表示电流强度（单位：安培，A）。
- 𝑄 表示通过导体横截面的电荷量（单位：库仑，C）
- 𝑡 表示时间（单位：秒，s）‌‌

# 电阻
决定式 $R = ρ ⋅ \frac{L}{A}$
- R：电阻。
- ρ：材料的电阻率，表示材料对电流的阻碍能⼒。
- L：导体的**⻓度**
- A：导体的**横截⾯积**

定义式 $R=\frac{U}{I}$

# 电容
## 决定式 $C = ε ⋅ \frac{S}{d}$
- ε： 电容器介质的介电常数，单位：法拉每⽶（F/m）
- S： 电容器极板的有效⾯积 ，单位：平⽅⽶（$m^2$ ）
- d： 极板间的距离，单位：⽶（m）

串并联
- 多电容器并联计算公式：C=C1+C2+C3+…+Cn
- 多电容器串联计算公式：1/C=1/C1+1/C2+…+1/Cn

## 定义式 
$C=\frac{Q}{U}$
- 如果带**1库的电量**时**两级间的电势差是1伏**，这个电容就是**1法拉**

$U_{目标电压}=U_{电源电压}(1-e^{-\frac{t}{RC} })$
- 电容的**充电速度**与**电容大小以及充电电流**有关
- 电容的**充电时间常数**：$\tau=R*C$
- 通常认为 3-5 $\tau$ 就充满了

# 电感
决定式 $L = μ\frac{N^2A}{l}$
- L： 电感，单位为**亨利（H）**
- μ： 导磁材料的磁导率，它反映了材料对磁场的导通能⼒，单位为亨利每⽶（H/m）
- N： 线圈的匝数，表示线圈绕的圈数
- A： 线圈的截⾯积，单位为平⽅⽶（m²）
- l： 磁路的⻓度，即线圈的⻓度，单位为⽶（m）

# 阻抗
- 电阻、容抗、感抗，这三者在交流电路中的综合表现称为阻抗
- 描述了电路中多种因素**对电流的总阻碍**

| 阻抗  | 描述                                  |
| --- | ----------------------------------- |
| 电阻  | 表示材料或元器件对电流的**固定阻碍**，主要是能量的耗散（发热）   |
| 容抗  | 由**电容**产⽣的**对电流的动态阻碍**，**随频率增加⽽减少** |
| 感抗  | 由**电感**产⽣的**对电流的动态阻碍**，**随频率增加⽽增加** |

## 容抗
决定式 $X_C = \frac{1}{2πfC}$
- X_C：容抗，单位为欧姆（Ω）
- f： 交流信号的频率，单位为赫兹（Hz）
- C： 电容值，单位为法拉（F）

总结出如下规律：
1. 信号频率不变的情况，电容的容值越⼩，容抗越⼤。
2. 电容容值不变的情况，信号的频率越⼩，容抗越⼤。

## 感抗
决定式 $X_L = 2πfL$
