# 总结
- BIOS/UEFI
   - 针对系统引导
   - 初始化硬件并提供运行环境
   - 决定引导设备的顺序（如硬盘、U 盘、网络引导等）。  
   - **UEFI 是 BIOS 的现代替代方案** 

- MBR/GPT
   - 针对磁盘分区
   - **BIOS 使用 MBR，UEFI 使用 GPT**
   - **GPT 是 MBR 的现代替代方案**
   - **MBR（主引导记录 MBR，Master Boot Record）**

# 概念
- **BIOS（Basic Input/Output System）**
  - 传统的固件接口，存储在主板上的 ROM 芯片中。
  - 通过读取主引导记录（MBR）找到引导加载程序。
- **UEFI（Unified Extensible Firmware Interface）**
  - 统一可扩展固件接口
  - 现代固件接口，支持更大的硬盘（GPT 分区表）和图形化界面。
  - 通过 EFI 系统分区（ESP）加载引导加载程序（`.efi` 文件）。


| **特性**            | **UEFI**                          | **BIOS**                          |
|---------------------|-----------------------------------|-----------------------------------|
| **存储支持**        | 支持 GPT，支持 >2TB 硬盘          | 仅支持 MBR，最大 2TB 硬盘         |
| **启动模式**        | 支持 UEFI 启动，基于 `.efi` 文件  | 传统 BIOS 启动，基于主引导记录    |
| **用户界面**        | 图形化界面，支持鼠标操作          | 文本界面，仅支持键盘操作          |
| **安全性**          | 支持安全启动                     | 无安全启动功能                   |
| **扩展性**          | 模块化设计，易于扩展             | 固定设计，扩展性差               |

# GPT 与 MBR 的对比
| 特性                | GPT                          | MBR                          |
|---------------------|------------------------------|------------------------------|
| 最大磁盘容量        | **理论上支持数 ZB**             | **最大 2 TB**                    |
| 最大分区数量        | 默认 128 个主分区           | 4 个主分区（或 3 主+1 扩展） |
| 冗余保护            | 有（主副分区表）            | 无                           |
| 校验机制            | CRC32 校验                  | 无                           |
| 分区标识            | GUID                        | 无（仅通过分区类型标识）     |
| 启动模式            | UEFI                        | BIOS                         |


# GPT 的基本概念
- GUID（Globally Unique Identifier）：全局唯一标识符，GPT 使用 GUID 来标识每个分区，确保分区的唯一性。
- 分区表：GPT 是一种分区表格式，用于描述磁盘上的分区信息。
- UEFI 支持：GPT 通常与 UEFI 固件配合使用，取代传统的 BIOS+MBR 组合。

# GPT 的特点
1. 支持大容量磁盘：
   - GPT 支持的磁盘容量上限为 2^64 扇区（理论上可支持数 ZB 的磁盘），远超 MBR 的 2 TB 限制。

2. 支持更多分区：
   - GPT 默认支持 128 个主分区（每个分区都有唯一的 GUID），而 MBR 仅支持 4 个主分区。

3. 冗余分区表：
   - GPT 在磁盘的开头和结尾各存储一份分区表副本，提供冗余保护，增强可靠性。

4. 分区校验：
   - GPT 使用 CRC32 校验分区表的完整性，确保数据未被损坏。

5. 兼容性：
   - GPT 磁盘包含一个保护性 MBR（Protective MBR），用于兼容旧版工具，防止误操作。
