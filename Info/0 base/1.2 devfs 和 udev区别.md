# devfs 和 udev
- `devfs` 和 `udev` 是 Linux 系统中用于**管理设备文件的两种机制**，
- **`devfs`：运行在内核空间，`udev`：运行在用户空间。**
- `udev` 
   - **是用户空间的设备管理工具，取代了 devfs。**
   - **通过内核的 udev 子系统和 sysfs 文件系统协作，动态管理 /dev 下的设备文件。**
   - 提供了高度可配置性，支持通过规则文件自定义设备文件的名称、权限和符号链接。
   - 是现代 Linux 系统的标准设备管理工具。   

# sysfs
- 是一种内核级的虚拟文件系统，挂载在 /sys 目录下。
- 提供了一个用户空间接口，用于访问**内核中的设备和驱动信息**。
- udev 使用 sysfs 提供的设备信息来动态创建和管理 /dev 下的设备文件。   

# /sys 和 /dev
- `/sys` 提供的是内核对象的状态和信息，主要用于系统管理和调试。
- `/dev` 提供的是设备文件接口，用户通过它与硬件设备交互。

它们的作用和区别如下：
1. **`/sys`**：
   - 是 `sysfs` 文件系统的挂载点。
   - 提供了一个用户空间接口，用于访问内核中的设备、驱动和内核对象信息。
   - 主要用于系统管理和调试，开发者可以通过读取或写入 `/sys` 下的文件来获取或修改内核对象的状态。
   - 例如，设备的属性信息、驱动程序的状态等都可以在 `/sys` 中找到。

2. **`/dev`**：
   - 是设备文件的存储目录。
   - 包含所有设备的节点文件，这些文件是用户空间程序与内核设备驱动交互的接口。
   - 通过 `/dev` 下的设备文件，用户可以对硬件设备进行操作，例如磁盘、终端、输入设备等。
   - `/dev` 的内容通常由 `udev` 动态管理，确保设备文件与实际硬件状态保持一致。
