
# 系统引导的主要阶段
## (1) 加电自检（Power-On Self-Test, POST）
- 触发条件：当计算机通电或按下电源按钮时，主板上的固件（BIOS 或 UEFI）开始执行。
- 主要任务：
  - 检查硬件是否正常工作（如 CPU、内存、硬盘、显卡等）。
  - 初始化硬件设备。
  - 如果检测到硬件故障，会通过蜂鸣器或屏幕提示错误信息。

## (2) 固件阶段（BIOS/UEFI）
- 初始化硬件并提供运行环境
- 决定引导设备的顺序（如硬盘、U 盘、网络引导等）。
- **UEFI 是 BIOS 的现代替代方案**
- **GPT 是 MBR 的现代替代方案**

## (3) 引导加载程序（Bootloader）
- 作用：引导加载程序负责加载操作系统内核。
- 常见引导加载程序：
  - **GRUB（GRand Unified Bootloader）：支持多操作系统引导。**
  - **Windows Boot Manager：Windows 系统的默认引导程序。**
- 任务：
  - 读取配置文件，确定要加载的操作系统。
  - 将操作系统内核加载到内存中。

## (4) 操作系统内核加载
- 内核初始化：
  - 加载操作系统内核到内存。
  - 初始化内核数据结构和驱动程序。
- 启动用户态进程：
  - 内核启动第一个用户态进程（如 Linux 的 `init` 或 `systemd`）。
  - 进入多用户模式，加载桌面环境或命令行界面。

# 系统引导的类型
- 冷启动（Cold Boot）：
  - 计算机从完全断电状态启动。
- 热启动（Warm Boot）：
  - 通过重启命令或按下重启按钮重新启动计算机。
- 网络引导（PXE Boot）：
  - 通过网络加载操作系统，常用于无盘工作站或大规模部署。
