# **POSIX 和 C 标准 总结**
- POSIX
    - 主要**面向操作系统**功能，提供了对底层系统资源的抽象。
    - 主要**面向类 Unix 系统**
    - linux内核部分实现了 POSIX标准
    - **musl 支持 POSIX 标准，边界是linux系统调用**
- C 标准
    - 主要**面向应用程序**开发，提供了通用的工具函数。
    - **musl 支持 C标准，边界是POSIX标准**

| **特性**         | **POSIX**                  | **C 标准**               |
|------------------|---------------------------|--------------------------|
| **定义机构**      | IEEE（POSIX 标准）         | ISO（C 标准）            |
| **接口层次**      | 底层接口                   | 高层接口                 |
| **文件操作接口**  | `open`                    | `fopen`                  |
| **返回值**        | 文件描述符（整数）          | `FILE` 指针              |
| **功能**         | 无缓冲，直接操作文件系统     | 提供缓冲和格式化功能      |
| **适用场景**      | 操作系统级别编程            | 跨平台应用开发            |

# POSIX（Portable Operating System Interface）
- 定义：POSIX 是 **IEEE 制定**的一组**操作系统接口标准**，旨在提高应用程序的可移植性。
- 范围：面向操作系统，与内核交互。主要定义了操作系统级别的接口，包括文件操作、进程管理、线程、信号等。

# C 标准（C Standard Library）
- 定义：C 标准由 **ISO 制定**，定义了 C 语言的核心语法和标准库函数。
- 范围：面向用户，提供与操作系统无关的高级抽象接口，适用于跨平台开发。

# musl 实现的标准
- **实现了大部分POSIX标准中的接口**
    - 进程管理：如 fork、exec、wait 等函数，用于创建和管理进程。
    - 线程管理：如 pthread_create、pthread_join 等函数，用于多线程编程。
    - 文件操作：如 open、read、write、close 等函数，用于文件的读写操作。
    - 信号处理：如 signal、sigaction 等函数，用于处理异步信号。
    - 时间管理：如 clock_gettime、nanosleep 等函数，用于时间和定时器操作。
    - 网络编程：如 socket、bind、listen、accept 等函数，用于网络通信。
    - 内存管理：如 mmap、munmap 等函数，用于内存映射和管理。
- **实现了 C标准 中的所有必需部分**
    - 输入输出（I/O）：如 printf、scanf、fopen、fclose、fread、fwrite 等函数，用于文件和标准流的操作。
    - 字符串处理：如 strlen、strcpy、strcmp 等函数，用于字符串操作。
    - 内存操作：如 malloc、free、memcpy、memset 等函数，用于动态内存分配和操作。
    - 数学函数：如 sin、cos、sqrt、pow 等函数，用于数学计算。
    - 时间函数：如 time、difftime、strftime 等函数，用于时间和日期处理。
    - 错误处理：如 errno、perror 等，用于错误状态的报告。
    - 类型转换：如 atoi、atof、strtol 等函数，用于数据类型的转换。

# musl 头文件定义
- **支持 POSIX 和 C 标准定义**，专为**嵌入式系统和资源受限的环境**设计
```
include     // 主要用于应用程序开发，提供通用的工具函数，如字符串操作、数学计算、内存管理等
├── arpa    // 提供与互联网协议相关的头文件
├── net     // 包含与网络接口相关的头文件
├── netinet // 用于处理 IP 地址、端口号、TCP/UDP 协议等
├── netpacket   // 包含与数据链路层（如以太网）相关的头文件
├── scsi        // 用于操作 SCSI 设备，如磁盘、光驱等
└── sys         // 包含系统级操作的头文件，提供文件系统、内存管理、进程控制等接口。
```

# 为了兼容
- musl-1.2.0/include/fcntl.h 是实际实现文件，提供了完整的功能定义。
- musl-1.2.0/include/sys/fcntl.h 是一个包装文件，用于兼容 POSIX 标准中规定的路径 <sys/fcntl.h>。
- 这种设计既满足了 POSIX 标准的要求，又保证了代码的兼容性和灵活性。
```
musl-1.2.0/include/sys/fcntl.h 内容

#warning redirecting incorrect #include <sys/fcntl.h> to <fcntl.h>
#include <fcntl.h>
```
