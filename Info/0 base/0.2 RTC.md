# RTC
- RTC（Real-Time Clock）设备是一种硬件时钟模块，用于提供当前的日期和时间信息。
- RTC 设备通常通过 `/dev/rtc` 或类似的设备文件暴露给用户空间，用户可以通过系统调用（如 `ioctl`）与 RTC 交互，执行时间读取、设置闹钟等操作。- 
- RTC 在嵌入式系统、服务器、物联网设备等场景中广泛应用，用于时间同步、定时任务调度等功能。

# 功能
1. **独立供电**：
   - RTC 通常由一块纽扣电池供电，即使系统断电，RTC 仍然可以保持运行，确保时间不会丢失。

2. **时间管理**：
   - RTC 提供精确的时间信息，包括秒、分钟、小时、日期、月份和年份。
   - 它支持闰年计算和 12/24 小时制。

3. **闹钟功能**：
   - RTC 可以设置闹钟时间，当达到指定时间时触发中断，用于唤醒系统或执行特定任务。

4. **周期性中断**：
   - RTC 支持周期性中断功能，可以以固定频率触发中断，用于定时任务。

5. **低功耗**：
   - RTC 的设计非常节能，适合长时间运行。
