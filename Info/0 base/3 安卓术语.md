# kapt 和 ksp
- kapt 是传统的注解处理工具，兼容性好但性能较低。
- ksp 是新一代工具，专为 Kotlin 优化，性能更高，推荐在 Kotlin 项目中使用。
- kapt (Kotlin Annotation Processing Tool):  
   - 是 Kotlin 官方提供的注解处理工具，用于支持 Java 的 annotationProcessor。
   - 通过将注解处理器生成的代码转换为 Java 源代码，适配 Kotlin 编译器。
   - 运行时会引入额外的 Java-to-Kotlin 映射层，性能较低。
- ksp (Kotlin Symbol Processing):  
   - 是 Kotlin 官方推出的新一代注解处理工具，专为 Kotlin 设计。
   - 直接操作 Kotlin 的抽象语法树（AST），无需 Java-to-Kotlin 映射层。
   - 性能更高，生成的代码更贴近 Kotlin。

```
apply plugin: 'kotlin-kapt'
kapt "com.google.dagger:dagger-compiler:$daggerVersion"

apply plugin: 'com.google.devtools.ksp'
ksp "com.google.dagger:dagger-compiler:$daggerVersion"
```
