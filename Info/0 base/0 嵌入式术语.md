# ASM 
- 汇编语言（Assembly Language）
- 特点：  
    - 低级别：与硬件关系紧密，适合操作寄存器、内存等底层资源。
    - 高效性：执行速度快，适合性能要求高的场景。
    - 可移植性低：与特定处理器架构绑定，不同架构的汇编代码不可通用。   

# BSP
- Board Support Package，嵌入式系统**为特定硬件平台提供的支持包**
- 主要组成部分包括：  
    - 启动代码：初始化硬件（如时钟、内存等）。
    - 硬件驱动：提供对硬件设备（如串口、网络、存储等）的访问。
    - 配置文件：定义硬件资源和操作系统的配置。

# BSD 
- 指 Berkeley Software Distribution，即伯克利软件分发版
- 是由美国加州大学伯克利分校开发的一系列类 Unix 操作系统的统称 
- 主要特点：  
    - 开源许可：BSD 使用宽松的 BSD 许可证，允许用户自由修改、分发甚至用于商业用途。
    - Unix 衍生：BSD 是 Unix 系统的一个重要分支，继承了 Unix 的设计哲学。
    - 稳定性和安全性：BSD 系统以其高稳定性和安全性著称，常用于服务器和嵌入式设备。
- 常见的 BSD 系统：  
    - FreeBSD
    - OpenBSD
    - NetBSD
    - DragonFly BSD    

# Cortex
- 是由 ARM（Advanced RISC Machine）设计的一系列处理器
- 主要分为以下三类：  
    - cortex-A：高性能处理器，适用于需要高级计算能力的应用，如智能手机、平板电脑和笔记本电脑。
    - cortex-R：实时处理器，专为安全关键和实时应用设计，如汽车系统和工业控制。
    - cortex-M：微控制器，针对低功耗和成本敏感的嵌入式系统优化，如物联网设备和可穿戴设备。

# MTD
- Memory Technology Device
- 主要用于管理和操作**非易失性存储器（如闪存、EEPROM 等）**
- 是 Linux 内核中的一个子系统，提供了对这些存储设备的统一接口
- **MTD是抽象层**，屏蔽了底层硬件的具体实现
- 它支持对存储设备的读、写、擦除等操作，特别适用于 NAND 和 NOR 闪存。

# Open Firmware
- OF（Open Firmware）​ 是一种固件接口标准（IEEE 1275标准定义）
- 核心目标是**标准化硬件设备的描述方式**，让操作系统无需硬编码硬件细节，而是通过固件提供的统一接口动态识别硬件
- **设备树**的语法和结构直接**继承自Open Firmware**的设备描述规范


# GIC
- 通用中断控制器（GIC，全称 Generic Interrupt Controller）
- 是 ARM 架构中用于管理和分发中断信号的硬件模块。
- GIC 的主要功能
    - 中断管理：接收和管理多个外部或内部中断信号。
    - 中断分发：根据配置将中断分发到特定的 CPU 核心。
    - 优先级处理：支持中断优先级机制，确保高优先级中断优先处理。
    - 中断屏蔽：支持屏蔽特定中断，避免干扰正常运行。
    - 中断触发模式：支持多种触发模式（电平触发或边沿触发）。

# 中断类型
- SPI（Shared Peripheral Interrupts）  
    - SPI 是共享中断，通常用于外设设备的中断信号。
    - 这些中断是所有 CPU 核心共享的，可以由任意一个核心处理。
    - 在设备树中，interrupts 属性的第一个单元为 0 时，表示这是一个 SPI 类型的中断。
- PPI（Private Peripheral Interrupts）
    - PPI 是私有中断，每个 CPU 核心都有一组独立的 PPI。
    - 这些中断通常用于与特定 CPU 核心相关的功能（如定时器）。
    - 在设备树中，interrupts 属性的第一个单元为 1 时，表示这是一个 PPI 类型的中断。 
- SGI：表示软件生成中断（Software Generated Interrupts）。       

#interrupt-cells = <3>;
#interrupt-cells 属性定义了中断描述符的单元数量。
<3> 表示中断描述符由 3 个单元组成，通常包括中断类型、中断号和触发方式
<2> 表示中断描述符由 2 个单元组成，通常包括中断号和触发方式。
