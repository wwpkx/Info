# 文件系统类型
- Ext2/3/4 
    - Linux extended file system, extfs，即 Linux 扩展文件系统
    - 一般将 Ext2 称为索引式文件系统，Ext3/Ext4 称为日志式文件系统
- NFS
    - 网络文件系统
    - NFS 包括两部分，**服务端及客户端**
    - 本地 NFS 客户端可以读写位于远端 NFS 服务器上的文件，就像访问本地文件一样   
- Cramfs
    - Compressed ROM File System      
    - **是一种只读的文件系统，主要用于存储只读数据，如固件或系统文件**   
    - 特点
        - 只读文件系统
        - 高效的存储利用
        - 轻量级
        - 直接访问压缩数据
- RamDisk    
    - RamDisk（内存磁盘）是一种将系统内存的一部分虚拟化为存储设备的文件系统
    - 常用于需要高性能临时存储的场景
    - 特点
        - 基于内存
        - 虚拟化存储设备
        - 灵活性
- 基于闪存        
    - jffs2
        - Journalling Flash File System，闪存日志型文件系统
        - 是一个可读写，压缩，日志型文件系统    
        - **最初只支持 NOR Flash，后来添加了 NAND Flash 的支持但不稳定**
    - ubifs
        - Unsorted Block Image File System
        - 是一种用于闪存设备的日志型文件系统，**专门为 NAND 闪存设计**
        - 组成：  
            - UBI 层：负责管理底层闪存的坏块、磨损均衡和擦除操作。
            - UBIFS 层：提供文件系统功能，如文件读写、目录管理等。
        - 与其他文件系统的对比：  
            - 与 JFFS2：UBIFS 支持更大的存储容量和更高的性能，适合大容量 NAND 闪存。
            - 与 EXT4 等传统文件系统：UBIFS 专为闪存设计，直接运行在原始闪存上，而传统文件系统需要运行在块设备（如 eMMC）上。
    - YAFFS/YAFFS2 
        - Yet Another Flash File System
        - **是专为 NAND 闪存设计的日志型文件系统**   
        - 优点
            - 高可靠性：通过日志结构和坏块管理，确保数据一致性和可靠性。
            - 高性能：优化了闪存的读写性能。
            - 轻量级：适合资源受限的嵌入式设备。
