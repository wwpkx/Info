# 设备树
## 概念
- 是一种**描述硬件信息的结构化数据格式**
- **将硬件信息从内核源码中剥离，以独立的二进制文件（DTB）形式传递给内核**
- 内核通过解析 DTB 动态识别硬件，实现 “一次编译，多硬件适配

## 组成
- DTS
	- Device Tree Source
	- 人类可读的文本文件，描述硬件信息（如外设、内存、中断等）
	- 位于内核`arch/<arch>/boot/dts/`（如`arch/arm/boot/dts/imx6ull.dts`）
- DTB
	- Device Tree Blob
	- DTS 经编译后的二进制文件，可被内核直接解析（体积小，适合嵌入式系统）
- DTC
	- Device Tree Compiler
	- 编译工具，将 DTS 转换为 DTB
	- `dtc -I dts -O dtb input.dts -o output.dtb`
	- 位于内核`scripts/dtc/`

## 工作流程​​
- 编译（DTC）
	- `dtc -I dts -O dtb -o imx6ull-evk.dtb imx6ull-evk.dts`
- 加载（Bootloader）
	- `load mmc 0:1 0x80800000 zImage  # 加载内核到0x80800000`
	- `load mmc 0:1 0x83000000 imx6ull-evk.dtb  # 加载DTB到0x83000000`
	- `bootz 0x80800000 - 0x83000000  # 启动内核，指定DTB地址`
- 解析（内核）
	- 加载 DTB
	- 构建设备树结构
		- 将 DTB 解析为内核内部的device_node结构体
		- 每个节点对应一个device_node
		- 存储在全局链表中。
	- 创建平台设备
		- 内核遍历device_node，为每个节点创建platform_device（平台设备）
		- 并将属性转换为设备资源（如reg转换为resource结构体的地址资源）
	- 驱动匹配与初始化
		- 驱动通过of_match_table（包含支持的compatible值）与platform_device匹配
		- 匹配成功后调用probe函数初始化设备
- 驱动匹配（compatible属性）
	- 是**硬件与驱动之间的接口规范**，定义了特定类型设备的节点和属性如何编写
