# 各种锁
- RCU锁（Read-Copy-Update）
- 自旋锁（Spinlock），循环检查锁（自旋）

| **特性**​      | **自旋锁**​          | **RCU锁**​         | **互斥锁**​     | **读写锁**​        |
| ------------ | ----------------- | ----------------- | ------------ | --------------- |
| **等待方式**​    | 循环检查锁（忙等待，不释放CPU） | 读无锁，写等待旧读完成       | 阻塞（睡眠，释放CPU） | 读/写可能阻塞（睡眠）     |
| **核心机制**​    | 原子操作+忙等待          | 版本化数据+延迟回收        | futex睡眠/唤醒   | 读锁计数器+写锁标志位     |
| **适用场景**​    | 极短临界区（<CPU周期）     | 读极多写极少（99%读+1%写）  | 长临界区（>CPU周期） | 读多写少（80%读+20%写） |
| **读支持**​     | 竞争锁（低并发）          | 无锁（高并发）           | 独占（低并发）      | 共享（中高并发）        |
| **写支持**​     | 竞争锁（低并发）          | 延迟替换（低频率）         | 独占（低并发）      | 独占（低频率）         |
| **CPU开销**​   | 高（持续自旋）           | 中（写操作同步开销）        | 低（睡眠不占CPU）   | 中（读锁计数器维护）      |
| **复杂度**​     | 简单（原子操作）          | 复杂（版本管理+回收）       | 中等（futex抽象）  | 中等（读写状态管理）      |
| **中断上下文支持**​ | 支持（需禁用中断）         | 支持（读侧临界区自动处理）     | 不支持（睡眠会崩溃）   | 不支持（睡眠会崩溃）      |
| **数据一致性**​   | 强一致性（锁期间独占）       | 最终一致性（读旧版本，写后渐变）  | 强一致性（锁期间独占）  | 强一致性（锁期间独占）     |
| **典型场景举例**​  | 内核链表修改、中断处理程序同步   | 路由表查询、文件系统inode缓存 | 文件写入、进程间同步   | 配置读取、缓存更新       |
