# Kconfig
- **用于软件配置的描述性语言和工具集**
- 核心功能
    - 让开发者能**可视化选择需要的功能**
    - 通过**依赖关系**确保配置的合理性
    - 最终生成一份精简的配置文件（`.config`），指导编译系统只编译选中的功能
- 基本组成
    - 配置项（config）：最基本的配置单元
    - 菜单（menu/endmenu）：组织配置项
    - 选择组（choice/endchoice）：互斥选项
    - source：引入其他 Kconfig 文件
- 工作流程
    - 编写 Kconfig 文件
    - 启动配置工具
        - make menuconfig（字符界面）
        - make xconfig（图形界面，Qt 依赖）
        - make gconfig（图形界面，GTK 依赖）
        - **defconfig**
	        - 预定义配置文件
	        - `make xxx_defconfig` 快速加载一套默认配置，避免从零开始配置
    - 用户配置
    - 生成 .config 文件
    - 编译阶段
