# MTD
## 概念
- Memory Technology Device
- 主要用于管理和操作非易失性存储器（如闪存、EEPROM 等）
- 是 Linux 内核中的一个子系统，提供了对这些存储设备的统一接口

## 作用
- **MTD是抽象层**，屏蔽了底层硬件的具体实现
- 它支持对存储设备的读、写、擦除等操作，特别适用于 NAND 和 NOR 闪存。

## 组成
- MTD 设备驱动：负责与具体的硬件交互，提供底层操作能力。
- MTD 子系统：提供对上层的抽象接口，屏蔽硬件差异。
- 文件系统支持：如 JFFS2、UBIFS 等文件系统，专门为 MTD 设备设计，用于管理闪存上的数据。

## 优点：  
- 提供统一的接口，简化了开发。
- 支持多种文件系统，灵活性高。
- 专为嵌入式系统设计，性能和可靠性较高
