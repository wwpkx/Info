# platform 总线

## 概念
- 平台总线（Platform Bus）是 Linux 内核中的一种**虚拟总线**
- 用于管理与特定平台的**设备和驱动程序**
- **主要用于那些不通过标准硬件总线连接的设备，而是直接集成在 SoC 上的设备**
- 平台总线是 Linux 内核中用于管理 SoC 集成设备的虚拟总线
- 平台总线根据设备名称匹配设备和驱动
- 它广泛应用于嵌入式系统和 SoC 平台的设备驱动开发中

## 核心概念
1. **平台设备（Platform Device）**
   - 表示与特定硬件平台相关的设备
   - 通常由硬件描述（如设备树或 ACPI 表）定义
   - 包含设备的资源信息（如内存地址、IRQ 等）
2. **平台驱动（Platform Driver）**
   - 用于管理平台设备的驱动程序
   - 通过匹配设备名称（`name`）与设备绑定
3. **平台总线（Platform Bus）**
   - **连接平台设备和平台驱动的虚拟总线**
   - **负责设备和驱动的匹配与绑定**

## 工作流程
1. **设备注册**
   - 平台设备通过 `platform_device_register()` 或设备树注册到平台总线
2. **驱动注册**
   - 平台驱动通过 `platform_driver_register()` 注册到平台总线
3. **设备与驱动匹配**
   - 平台总线根据设备名称（`name`）匹配设备和驱动
4. **驱动绑定**
   - 匹配成功后，调用驱动的 `probe()` 函数初始化设备

## 关键数据结构
- platform_device
	- name
	- id
	- resource
	- num_resources
	- dev
- resource
	- start
	- end
	- flags
	- name
- platform_driver
- platform_get_resource

## 优点
1. **简化设备管理**
   - 适合管理 SoC 上的集成设备
2. **灵活性**
   - 支持通过设备树或 ACPI 动态描述硬件
3. **统一接口**
   - 提供标准化的设备和驱动匹配机制
