# 可执行程序

## 概念
- 核心目标是**把静态的可执行文件，转化为动态的、可运行的进程**
- 本质是 “地址空间映射 + 运行环境初始化” 的结合
- 可执行文件格式：ELF（Executable and Linkable Format）

## 加载
- 直接运行程序（如 `./a.out`）
- `fork()` 复制父进程地址空间
- `execve()` 销毁原地址空间，装载新程序
- shell 进程调用 `execve`，装载 `a.out` 并替换自身地址空间

execve 系统调用 → 内核解析 ELF → 初始化地址空间与 VMA → 建立内存映射（惰性加载）→ 初始化用户栈（参数/环境变量）→ 切换到用户态 → 动态链接器加载共享库（动态链接程序）→ _start 初始化 → main 执行
