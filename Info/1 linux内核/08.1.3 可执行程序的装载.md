# 可执行程序

## 概念
- 核心目标是**把静态的可执行文件，转化为动态的、可运行的进程**
- 本质是 “地址空间映射 + 运行环境初始化” 的结合
- 可执行文件格式：ELF（Executable and Linkable Format）
- `fork()` + `execve()`

## 加载
- 直接运行程序（如 `./a.out`）
- 通过`fork()`创建子进程
- `fork()` 复制父进程地址空间
- 子进程调用`execve()`加载新程序，覆盖原有进程的上下文
- execve
	- execve 系统调用 
	- 内核解析 ELF 
	- 创建新的虚拟地址空间
	- 建立 “虚拟地址→磁盘文件” 的映射（惰性加载核心）
	- 初始化用户栈（参数/环境变量）
	- 设置程序入口，切换回用户态
	- 用户态初始化（`_start` → `main`）
