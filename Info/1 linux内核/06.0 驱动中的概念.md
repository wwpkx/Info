# 驱动
## 常见概念
- 设备号
    - 分为
        - 主设备号
            - 标识设备的类型或类别。
            - 每种设备类型对应一个主设备号。
            - 例如，硬盘的主设备号可能是 8，串口的主设备号可能是 4。
        - 次设备号 
            - 标识同一类型设备中的具体设备实例。
            - 例如，/dev/sda 和 /dev/sdb 可能有相同的主设备号，但次设备号不同。            
    - 分配规则
        - 静态分配
            - 设备号由 Linux 内核维护的 Documentation/admin-guide/devices.txt 文件定义
            - 主设备号范围：
                - 0-255：传统设备号范围。
                - 256-4095：扩展设备号范围。
            - 次设备号范围：
                - 每个主设备号可以分配多个次设备号，通常为 0-255。            
        - 动态分配
            - 使用 alloc_chrdev_region() 或 register_blkdev() 等内核 API 动态分配主设备号和次设备号
- 设备节点
    - 设备节点是位于 /dev 目录下的特殊文件，用于与内核中的设备驱动程序交互
    - 通过设备节点，用户空间的程序可以像操作普通文件一样访问硬件设备。
    - **设备文件 和 设备节点**
        - 设备文件，表示硬件设备的文件接口
        - 设备节点，设备文件的具体实现，包含主设备号和次设备号
    - 创建
        - `mknod <设备节点路径> <类型> <主设备号> <次设备号>`
        - `mknod /dev/mydevice c 200 0`
    - 查看
        - 使用 ls -l 查看设备节点的主设备号和次设备号
        - 使用 cat /proc/devices 查看已注册的主设备号
