# 内核源码来源
- linux内核源码
- 芯片原厂内核源码
    - 例如恩智浦，三星等
    - 会不定期在 linux 官网下载稳定版本的内核
    - 将其适配到各个芯片上
    - **形成自己的维护版本**
    - NXP 的仓库：[GitHub - nxp-imx/linux-imx: i.MX Linux kernel](https://github.com/nxp-imx/linux-imx)
- 板卡厂商内核源码
    - 到芯片原厂获取已经适配好的稳定版本的内核
    - 进行外设接口的适配
    - 给用户提供移植好的板级开发包。
    - 板卡厂商也会对移植好的内核版本进行维护，例如一些 BUG 修复或者物料替换
