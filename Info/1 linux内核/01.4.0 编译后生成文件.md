# 编译后生成文件
| 名称         | 所在目录                     | 说明                                     |
| ---------- | ------------------------ | -------------------------------------- |
| vmlinux    | 内核源码根目录下                 | 内核原始elf格式镜像,其中包含了可执行的二进制指令，调试信息，符号表等内容 |
| System.map | 内核源码根目录下                 | 符号表                                    |
| Image      | arch/arm/boot            | 内核原始 bin格式镜像                           |
| zImage     | arch/arm/boot            | 经压缩和添加头信息后的 bin镜像                      |
| vmlinux    | arch/arm/boot/compressed | 经压缩和添加头信息后的 elf镜像                      |
| .dtb       | arch/arm/boot/dts        | 设备树二进制文件                               |
