# 内核
## 编译内核 和 设备树
- `$ export ARCH=arm `
- `$ export CROSS_COMPILE=arm-linux-gnueabi- `
- `$ make vexpress_defconfig `
- `$ make menuconfig`
- `$ make bzImage --j4 ARCH=arm CROSS_COMPILE=arm-linux-gnueabi- `
    - `linux-4.1.15-elf1/arch/arm/boot/路径下生成 bzImage`
- `$ make dtbs`
    - `linux-4.1.15-elf1/arch/arm/boot/dts 路径下生成相关的 dtb 文件`
- `$ make modules`
    - `make modules_install INSTALL_MOD_PATH=/home/elf/work/`
    - 将导出的模块压缩打包为 modules.tar.bz2

## 制作根文件系统
- `$ cd busybox `
- `$ export ARCH=arm `
- `$ export CROSS_COMPILE=arm-linux-gnueabi- `
- `$ make menuconfig`
- `$ make`
- `$ make install`
