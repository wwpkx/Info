# 内核启动流程
- 固件阶段（Firmware：BIOS/UEFI）
	- 初始化基础硬件
	- 加载引导程序（Bootloader）
- 引导程序阶段（Bootloader）
	- 加载内核 和 initrd，传递启动参数
	- 跳转到内核入口（如`stext`）
- 内核汇编入口
	- 解压缩内核，初始化 CPU / 内存	
	- 跳转到 start_kernel
- start_kernel	
	- **初始化内存管理**
	- **初始化中断与异常**
	- **初始化进程管理**：创建**进程0（Idle进程）**，这是内核的“根进程”
	- **初始化设备驱动**
	- **初始化文件系统**
- rest_init
	- **进程1（Init进程）**
		- 通过`kernel_thread`创建，执行`kernel_init`函数
		- 挂载根文件系统
			- 挂载临时根文件系统（Initramfs）
				- 进程1执行`/init`脚本，加载根文件系统所需的驱动
			- 挂载真正的根文件系统
		- 启动用户空间服务
			- 传统SysV init
				- 通过`/etc/inittab`文件设置**运行级别**
			- 现代systemd
				- 读取`/etc/systemd/system/default.target`文件：确定默认目标
				- 启动目标依赖的服务
				- 启动登录界面
	- **进程2（kthreadd进程）**
		- 由进程0直接创建，是**内核线程的管理者**
		- 负责创建和调度所有内核线程
