# 进化史
- 正常的驱动
	- 设备和驱动在一起
- platform 设备驱动
	- 设备和驱动分开
- 设备树
	- 设备使用设备树描述
	- 驱动还是使用 platform驱动
- Pinctrl 子系统
- GPIO 子系统
- ioctl
- 中断
	- 中断上文 和 中断下文
	- 中断下文 -- tasklet
		- 比如，按下按键后，循环输出100个数字
	- 等待队列
		- 比如，按键按下后，才会触发读操作
		- wait_queue
	- 中断下文 -- 工作队列
		- 比如，按下按键后，循环输出100个数字
- 内核定时器
	- 按键消抖
- 输入子系统
	- 输入设备一般包括键盘，鼠标，触摸屏 等，在内核中都是以输入设备出现的。
