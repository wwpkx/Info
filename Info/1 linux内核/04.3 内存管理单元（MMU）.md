# 内存管理单元（MMU）

## **总结**
| **功能**         | **描述**                                                                 |
|------------------|--------------------------------------------------------------------------|
| **地址转换**     | 将虚拟地址转换为物理地址，支持虚拟内存机制。                             |
| **内存保护**     | 防止非法访问，确保进程之间的内存隔离。                                   |
| **缓存控制**     | 管理缓存一致性，优化内存访问性能。                                       |
| **分页/分段支持**| 支持分页或分段机制，灵活分配内存资源。                                   |


# **1. MMU 的主要功能**

## **1.1 地址转换**
- **虚拟地址到物理地址的映射**：
  - MMU 将 CPU 生成的虚拟地址（Virtual Address）转换为物理地址（Physical Address）。
  - 通过页表（Page Table）或段表（Segment Table）实现映射。
- **分页机制**：
  - 虚拟内存被划分为固定大小的页（Page），物理内存被划分为页框（Page Frame）。
  - MMU 使用页表记录虚拟页与物理页框的对应关系。
- **分段机制**：
  - 虚拟内存被划分为不同大小的段（Segment），每个段有自己的基地址和长度。
  - MMU 使用段表记录段的基地址和限制信息。

## **1.2 内存保护**
- **进程隔离**：
  - MMU 确保每个进程只能访问自己的虚拟地址空间，防止进程之间的内存干扰。
- **访问权限**：
  - MMU 为每个内存区域设置访问权限（如只读、读写、执行），防止非法操作。
- **异常处理**：
  - 如果进程访问了无效地址或违反了权限，MMU 会触发异常（如页面错误）。

## **1.3 缓存控制**
- **缓存一致性**：
  - MMU 管理 CPU 缓存和主存之间的数据一致性，避免数据不一致问题。
- **缓存策略**：
  - MMU 可以为不同的内存区域设置缓存策略（如缓存启用/禁用、写回/直写）。

## **1.4 分页和分段支持**
- **分页（Paging）**：
  - 通过固定大小的页简化内存管理，减少外部碎片。
- **分段（Segmentation）**：
  - 提供逻辑分段，便于程序员管理代码段、数据段和堆栈段。

# **2. MMU 的工作原理**

## **2.1 虚拟地址到物理地址的转换过程**
1. **CPU 生成虚拟地址**：
   - 程序访问内存时，CPU 生成虚拟地址。
2. **MMU 查找页表/段表**：
   - MMU 根据虚拟地址查找页表或段表，获取对应的物理地址。
3. **物理地址访问内存**：
   - MMU 将物理地址发送到内存控制器，完成内存访问。

## **2.2 页表机制**
- **多级页表**：
  - 为了减少页表占用的内存，MMU 使用多级页表（如二级页表、三级页表）。
- **TLB（Translation Lookaside Buffer）**：
  - MMU 使用 TLB 缓存最近的地址转换结果，加速地址转换过程。

## **2.3 页面置换**
- **页面错误**：
  - 如果虚拟地址对应的页面不在物理内存中，MMU 触发页面错误。
- **页面置换算法**：
  - 操作系统根据算法（如 LRU、FIFO）选择页面进行置换。
