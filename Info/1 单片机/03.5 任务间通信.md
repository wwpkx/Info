# 任务间同步及通信
## 同步机制
- 二值信号量（Binary Semaphore）
	- 可能导致优先级反转，**适合简单同步**
	- 相关 API：
		- xSemaphoreCreateBinary：创建二值信号量。
		- xSemaphoreTake / xSemaphoreGive：获取/释放信号量。
- 互斥信号量（Mutex）
	- **具有优先级继承机制，避免优先级反转**，适合资源保护
	- 相关 API：
		- xSemaphoreCreateMutex：创建互斥信号量。
		- xSemaphoreTake / xSemaphoreGive：获取/释放信号量。	
- 计数信号量（Counting Semaphore）
	- 用于管理多个相同资源的访问，例如固定数量的缓冲区或硬件接口
	- 相关 API：
		- xSemaphoreCreateCounting：创建计数信号量。
		- xSemaphoreTake / xSemaphoreGive：获取/释放信号量。		
- 事件标志组（Event Groups）
	- 通过**位操作**实现任务间事件同步
	- 特点：
		- 每个位表示一个独立事件。
		- 支持等待单个或多个事件。
	- 适用场景：复杂的任务同步。
	- 相关 API：
		- xEventGroupCreate：创建事件标志组。
		- xEventGroupSetBits / xEventGroupWaitBits：设置/等待事件位。	
		
## 通信机制
- 队列（Queue）
	- 任务间或任务与中断间传递数据
	- 相关 API：
		- xQueueCreate：创建队列。
		- xQueueSend / xQueueReceive：发送/接收数据。
		- xQueueSendFromISR / xQueueReceiveFromISR：中断中操作队列。
- 队列集（Queue Set）	
	- 允许任务同时监听多个队列或信号量
	- 相关 API：
		- xQueueCreateSet：创建队列集。
		- xQueueAddToSet / xQueueSelectFromSet：添加/等待队列集事件。	

## 任务通知
- 每个任务都有一个**内置的通知值**	
- 任务通知支持事件通知、计数操作和数据传递
- 相关 API：
	- 发送通知
		- xTaskNotify：通用通知函数，支持多种操作。
		- xTaskNotifyAndQuery：在通知的同时查询之前的通知值。
		- xTaskNotifyGive：简化计数操作，通知值加 1。		
	- 等待通知
		- xTaskNotifyWait：更通用，支持读取和清除通知值，适合复杂场景。
		- ulTaskNotifyTake：专注于计数操作，简单高效，适合计数信号量替代。
