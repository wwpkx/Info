# 存储器映射概览
![](../../photo/Pasted%20image%2020250908192042.png)
- **物理地址空间划分**
- 使用**结构体封装寄存器**
- 裸机模式下，程序直接访问​**​物理地址​**​（地址与硬件寄存器/存储一一对应）
- **嵌入式内存映射**
	- 是​**​硬件定义的“物理地址 - 功能模块”直接映射​**​
	- 追求“实时性、硬件可控性”
- **Linux内存映射**
	- 是​**​操作系统定义的“虚拟地址 - 软件资源”抽象映射​**​
	- 追求“多任务隔离、资源动态调度、安全扩展性”。

# 存储器映射 应用场景

| **场景​**​ | ​**​涉及块号​**​ | ​**​操作示例​**​                                                   |
| -------- | ------------ | -------------------------------------------------------------- |
| 程序烧录     | Block 0      | 将代码写入`0x0800 0000 ~ 0x0807 FFFF`区域，需通过JTAG/SWD或UART Bootloader |
| 外设控制     | Block 2      | 配置GPIOA的`ODR`寄存器（`0x4002 0014`）控制引脚电平                          |
| 外部存储器扩展  | Block 3/4    | 通过FSMC接口访问外部NOR Flash（`0x6000 0000`映射到Bank1）                   |
| 内核中断管理   | Block 7      | 配置NVIC寄存器（`0xE000 E000`）设置中断优先级                                |
# 存储器映射详表
| **块号​**​        | ​**​用途​**​                  | ​**​子区域划分​**​                                                                                                                                                         | ​**​备注​**​                                              |
| --------------- | --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| ​**​Block 0​**​ | ​**​内部FLASH​**<br>**程序烧录**​ | 1. ​**​主存储器​**​  <br>- 存储程序代码（1MB）  <br>2. ​**​系统存储器​**​  <br>- Bootloader（出厂固化）  <br>3. ​**​OTP区域​**​  <br>- 512字节一次性写入（加密密钥）  <br>4. ​**​选项字节​**​  <br>- 配置读保护、看门狗等 | - 主存储器支持双Bank切换（1MB容量）  <br>- **系统存储器仅可读，用于串口/USB下载程序** |
| ​**​Block 1​**​ | ​**​内部SRAM​**​              | 1. ​**​CCM RAM​**​  <br>- 64KB高速缓存（仅CPU直接访问）  <br>2. ​**​SRAM1​**​  <br>- 112KB通用数据存储  <br>3. ​**​SRAM2​**​  <br>- 16KB临时数据  <br>4. ​**​SRAM3​**​  <br>- 64KB共享数据区    | - CCM RAM提升实时性（如信号处理）  <br>- SRAM3支持DMA访问               |
| ​**​Block 2​**​ | ​**​片上外设​**​                | 1. ​**​APB1总线​**​  <br>- 低速外设（GPIO、UART）  <br>2. ​**​APB2总线​**​  <br>- 高速外设（ADC、SPI）  <br>3. ​**​AHB总线​**​  <br>- 高速外设（DMA、以太网）                                       | - APB1时钟频率42MHz，APB2为84MHz  <br>- AHB总线支持突发传输           |
| ​**​Block 3​**​ | ​**​外部存储器扩展1​**​            | 1. ​**​FSMC Bank1​**​  <br>- NOR Flash  <br>2. ​**​Bank2​**​  <br>- NAND Flash                                                                                        | - 需配置FSMC时序（地址/数据总线复用）                                  |
| ​**​Block 4​**​ | ​**​外部存储器扩展2​**​            | 1. ​**​Bank3​**​  <br>- PSRAM（伪静态RAM）  <br>2. ​**​Bank4​**​  <br>- SDRAM                                                                                              | - SDRAM需初始化时序控制器                                        |
| ​**​Block 5​**​ | ​**​外部存储器扩展3​**​            | 1. ​**​Bank5​**​  <br>- NOR Flash扩展  <br>2. ​**​Bank6​**​  <br>- NAND Flash扩展                                                                                         | - 支持大容量存储（如16位数据总线）                                     |
| ​**​Block 6​**​ | ​**​保留区​**​                 | 无                                                                                                                                                                     | - 未使用，预留未来扩展                                            |
| ​**​Block 7​**​ | ​**​内核外设​**​                | 1. ​**​NVIC​**​  <br>- 中断控制器  <br>2. ​**​SysTick​**​  <br>- 系统滴答定时器  <br>3. ​**​MPU​**​  <br>- 内存保护单元                                                                 | - 仅内核模式访问  <br>- MPU防止非法内存访问                            |
# 存储器映射 和 寄存器映射
- 寄存器映射是存储器映射的子集
- **存储器映射是 “大框架”**
	- 它将 CPU 的 4GB 地址空间划分为 “存储区”“外设区” 等区域
- **寄存器映射是 “小细节”**
	- 它在 “外设区” 内部，给每个外设的寄存器分配具体地址

| **维度​**​     | ​**​存储器映射​**​         | ​**​寄存器映射​**​    |
| ------------ | --------------------- | ---------------- |
| ​**​范围​**​   | 整个存储资源（Flash、RAM、外设等） | 外设寄存器（GPIO、定时器等） |
| ​**​粒度​**​   | 以块（512MB）或页（4KB）为单位   | 以4字节为单元          |
| ​**​实现方式​**​ | 厂商预定义或用户自定义           | 通过结构体、宏定义别名      |
| ​**​典型应用​**​ | 启动配置、外设地址分配           | 外设初始化、状态控制       |
