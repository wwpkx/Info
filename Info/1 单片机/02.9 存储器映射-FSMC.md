# FSMC
## 概述
- FSMC（Flexible Static Memory Controller，灵活**静态**存储控制器）
- 作用
	- 作为 **STM32** 与**外部静态存储器**之间的 “**桥梁**”
	- 通过可编程的**时序控制和地址映射**
	- 实现 CPU 对外部存储器的高速访问
- 目的
	- **解决片内存储容量不足的问题**
	- 用于扩展**外部静态存储器**
	- 通过**统一的接口**连接多种类型的外部存储设备
## 具体功能
- 多类型支持​
	- **支持同步/异步访问的静态存储器**（NOR Flash、SRAM、PSRAM、NAND Flash、LCD 控制器等）
	- **不支持动态存储器**（如SDRAM）
- 提供灵活的时序配置，匹配不同存储器的读写速度要求；
- 将外部存储器映射到 STM32 的统一地址空间
- 支持 8 位 / 16 位数据宽度
- 地址 / 数据复用支持
