# 概述

## 介绍
- 8051单片机，8位微控制器
- STC89C52RC-40I-LOFP44
    - stc89公司型号， C电压5.5--3.3V， 52硬盘52k， RC内存512字节
    - 40工作频率40Mhz， I工业级，LOFP封装，44引脚
- 44个引脚
    - 电源 vcc gnd
    - 复位 rst
    - 时钟 xtal1 xtal2
    - 通用输入输出，gpio
        - 通用性，只有高低两个电平
        - P0 P1 P2 P3 P4, 共39个
        - 复用引脚，除了gpio还有其他功能
- 最小系统
    - 电源
    - 复位电路
    - 晶振电路

## 开发环境
- **硬件**（开发板），**核心板**和**扩展版**
- 软件
    - 代码编辑
        - **Keil**
            - 运行在Windows系统
            - 提供了代码编辑、代码编译、仿真和调试
    - 代码编译，**Keil C51 Compiler**
        - 专门用于 51 单片机的 C 语言编译器
        - 基于 ANSI C（C89/C90）标准
    - 程序烧录，**STC-ISP**
        - 是STC公司专门为STC芯片提供的程序烧录工具，用于将程序写入单片机

## 时钟
- 时钟周期
    - 时钟脉冲信号震荡源的周期，11.0592MHZ
    - 每个周期大于 0.09 微妙
- 机器周期
    - 一个基本操作需要的时间
    - 在烧写程序时可以选择
    - MCU 分频
	    - 12T（默认）
		    - 12分频
		    - 1个机器周期 == 12个时钟周期，约1.08微妙
		- 6T
- 指令周期
    - 完成一条指令需要的时间，有几个机器周期组成
    - 分为 单机器周期指令、双机器周期指令、四机器周期指令

## 工作频率≠晶振频率
- **晶振频率（11.0592MHz）, 外设兼容性**
    - 是单片机的**基准时钟源**
    - **适配串口等外设**的精确需求，确保通信等功能稳定
- **工作频率（40MHz）, 性能**
    - 是通过**内部倍频**实现的 CPU 运行频率
    - 用于**提升运算速度**
