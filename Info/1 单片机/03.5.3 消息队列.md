# 消息队列
## 消息队列
- 概念
	- 是任务间通信的核心机制之一，用于在任务之间或任务与中断之间传递数据
	- 会有 **优先级反转** 问题
- 特点
	- 数据传递：  
		- 消息队列可以存储**固定大小的数据项**（如结构体、整数等）。
		- 任务或中断可以通过队列发送或接收数据。
	- 线程安全：  
		- FreeRTOS 内部实现了队列的线程安全机制，确保多任务环境下的正确性。
	- 阻塞机制：  
		- 任务在发送或接收队列时可以选择阻塞，直到队列有空间或有数据。
	- 优先级支持：  
		- 高优先级任务可以优先访问队列。	
- 常用 API		
	- xQueueCreate
	- xQueueSend/xQueueSendFromISR
	- xQueueReceive/xQueueReceiveFromISR

## 队列集
- 概念
	- 允许任务同时**等待多个队列或信号量**中的任意一个变为可用
	- 它适用于需要从多个数据源接收数据或事件的场景
- 特点
	- 多路复用：  
		- 任务可以通过队列集同时监听多个队列或信号量。
	- 统一接口：  
		- 队列集将多个队列或信号量组合在一起，任务只需等待队列集即可。
	- 线程安全：  
		- FreeRTOS 内部保证队列集操作的线程安全。
	- 限制：  
		- 队列或信号量必须是空的，才能添加到队列集中。
- 常用 API
	- xQueueCreateSet
	- xQueueAddToSet
	- xQueueRemoveFromSet
	- xQueueSelectFromSet
