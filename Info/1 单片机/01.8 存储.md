# 存储
## ROM（硬盘）
- 定义
	- Read-Only Memory，只读存储器
	- 断电后可保持数据
	- **ROM 属于 NVM**（Non-Volatile Memory，非易失性存储器）范畴
	- 最开始是只读，后来慢慢发展为可读写，依旧保持了这个说法
- 分类
	- ROM
		- MASK ROM, 掩膜ROM
	- PROM
		- Programmable Read-Only Memory，可编程只读存储器
		- 只能写一次
	- EPROM
		- Erasable Programmable Read-Only Memory，可擦写可编程只读存储器
		- 用**紫外线照射**可以擦除数据
	- EEPROM
		- Electrically Erasable Programmable Read-Only Memory，可擦写可编程只读存储器
		- 用**电信号**可以擦除数据
	- Flash，闪存
		- 定义
			- Flash EEPROM Memory
			- **按扇区block操作，而EEPROM按字节操作**
		- NAND flash
			- **大容量，常用于固态硬盘**
			- 数据线和地址线复用，不能利用地址线随机寻址
		- NOR flash
			- 速度快，容量小，用作代码存储
			- 数据线和地址线分用，可以实现ram用期样随机寻址功能，程序直接运行

## RAM（内存）
- 定义
	- Random Access Memory，随机存储器
	- 断电后不可保持数据
- SRAM
	- 静态随机存储器，**读写快**
	- **常用于cpu缓存**
- DRAM
	- 定义
		- 动态随机存储器，**读写慢**
		- **常用于内存**
	- SDRAM
		- (Synchronous Dynamic Random Access Memory): 同步动态随机存储器
		- **同步**: 内存工作需要有**同步时钟**
		- **动态**：存储阵列需要不断的刷新来保证数据不丢失
		- **随机**：自由指定地址进行数据读写
	- DDR SDRAM
		- **Double Data Rate SDRAM**
		- 速度 = SDRAM x 2
	- DDR2 SDRAM， 速度 = DDR x 2 = SDRAM x 4
	- DDR3 SDRAM
	- DDR4 SDRAM
