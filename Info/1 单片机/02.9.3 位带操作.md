# 概念
- 51 单片机，通过关键字 sbit 对单片机 IO 口进行位定义
- STM32
	- 访问位带别名区来实现
	- 即将每个比特位膨胀成一个 32 位字，当访问这些字的时候就达到了访问比特的目的

# 好处

| **特性​**​      | ​**​位带操作​**​   | ​**​传统“读-改-写”​**​ |
| ------------- | -------------- | ----------------- |
| ​**​操作步骤​**​  | 1 次访存（直接写别名地址） | 3 次访存（读→改→写）      |
| ​**​原子性​**​   | 硬件保证，不可中断      | 需软件保护（如关闭中断）      |
| ​**​代码复杂度​**​ | 宏定义简化操作        | 需手动位运算            |
| ​**​适用场景​**​  | 高频位操作、中断服务程序   | 低频或简单位操作          |

# 支持位带操作的区域
- STM32F1 中有两个区域支持位带操作
- 一个是 SRAM 区的最低 1MB 范围
- 一个是片内外设区的最低 1MB 范围（APB1、APB2、AHB 外设）
