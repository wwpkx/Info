# USART
- USART概念
	- `USART == UART + 同步通信`
	- 常用于对数据传输准确性和速度要求较高的场合
	- 额外增加了一根时钟线（如 SCK）
- UART 实现方式
	- 轮询的方式接收
+		- 发送和接受使用同一个缓冲区
+		- 不停的判断缓冲区是否为空
+		- `while ((USART1->SR & USART_SR_RXNE) == 0)`
	- 中断的方式接收
- UART 案例
	- 重定向printf
	- 重写fputc
		- 原来将字符串写到file
		- 现在将字符串写到串口
