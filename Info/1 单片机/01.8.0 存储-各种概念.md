# 存储
## 按照存储介质划分
- 磁盘
	- 使用**磁性**介质存储数据
	- 非易失性存储
- nvm
	- NVM（Non-Volatile Memory，非易失性存储器）
	- **一种存储技术，断电后数据仍然保留**
	- 常见的 NVM 技术包括 NAND 闪存、NOR 闪存等，广泛应用于 SSD、U 盘、SD 卡等设备

## NVM 和 MMC 比较
- MMC（MultiMedia Card）
- 一种基于 NAND 闪存的存储设备标准，主要用于便携式设备
- NVM 包含 MMC

## nvm 和 flash
- **Flash 是 NVM 的一种实现形式**, 是一种具体的非易失性存储技术
- Flash 通常基于 NAND 或 NOR 技术。 

## 协议
- SATA（Serial ATA）
	- SATA（Serial ATA）
	- 一种**传统的存储接口协议**
	- 主要用于连接**硬盘驱动器（HDD）和固态硬盘（SSD）**
- NVMe
	- **NVMe（Non-Volatile Memory Express）**  
	- NVMe 是一种协议，旨在提升存储设备的通信效率
	- **主要用于高性能 SSD（如 NVMe SSD）**，适合需要快速数据传输的场景。  
	- 与SATA比较
		- 性能：NVMe 明显优于 SATA，提供更高的带宽和更低的延迟。
		- 成本：SATA 更经济，适合对性能要求不高的场景。
		- 应用：NVMe 适合高性能需求，SATA 适合传统存储需求	

## 存储卡
### mmc
- mmc 概念
    - Multimedia Card，一种基于 NAND 闪存的存储设备标准，主要用于便携式设备
    - 支援兩種通訊模式：MMC 模式及SPI模式
- 发展方向
    - SD卡
        - mmc + 安全
        - Secure Digital，安全数码卡
    - emmc
        - mmc + embed,缩小    
        - 嵌入式多媒体卡（Embedded Multimedia Card）
### UFS
- 通用闪存存储（英文：Universal Flash Storage）
- 被视作嵌入式多媒体存储卡（embedded Multi Media Card，eMMC）和SD卡的取代者
