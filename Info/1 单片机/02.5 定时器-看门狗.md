# 看门狗
## 概述
- 内部自带了两个看门狗
- 一个是**独立看门狗 IWDG**，另一个是**窗口看门狗 WWDG**

## 独立看门狗 IWDG
### 概述
- 看门狗功能由 VDD 电压域供电，在停止模式和待机模式下仍能工作
- 原理
    - 一个 12 位递减计数器
    - 当计数器从某一个值**递减到 0 时，系统就会产生一次复位**
    - 如果在**计数器递减到 0 之前刷新了计数器值（喂狗）**，那么系统就不会产生复位
### 配置步骤
- 取消寄存器写保护，对 IWDG_KR 寄存器写入代码 0x5555
- 设置看门狗预分频系数和重装载值
- 重载计数器值(喂狗)(给 IWDG_KR 寄存器写入 0XAAAA)
- 开启 IWDG(给 IWDG_KR 寄存器写入 0XCCCC)
