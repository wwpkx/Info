# 定时器
## SysTick
- 概念
	- 系统定时器
	- 是 Cortex-M3 内核的一个外设，被嵌入在 NVIC 中
	- 是一个 24 位向下递减的定时器
- SysTick 定时器寄存器
	- CTRL 寄存器
	- LOAD 寄存器，重装载数值
	- VAL 寄存器，当前数值
	- CALIB 寄存器，校准数值寄存器，出厂时已经设置
- 操作步骤
	- 设置 SysTick 定时器的时钟源。
	- 设置 SysTick 定时器的重装初始值（如果要使用中断的话，就将中断使能打开）。
	- 清零 SysTick 定时器当前计数器的值。
	- 打开 SysTick 定时器。
- delay函数的思路
	- 轮询
		- 循环判断ctrl寄存器中的countFlag
		- led灯delay时，按键delay来了
			- 两个delay冲突，delay的时间不一样
			- 结束条件都是判断 countFlag
	- 中断
		- 定义一个全局滴答
		- 每个delay从自己的滴答数开始判断，直到delay结束
## 定时器			
- 概述
	- 2个基本定时器(TIM6,7)
	- 4个通用定时器(TIM2-5)
	- 2个高级定时器(TIM1和TIM8)
- 基本定时器
	- 各包含一个16位自动装载计数器
	- 这2个定时器是互相独立的，不共享任何资源
	- 只能向上计数
- 通用定时器
	- 多种时钟源
		- 内部时钟（Internal Clock）：由 APB 总线时钟（APB1 或 APB2）提供。
		- 外部时钟模式 1（External Clock Mode 1）：通过 TIx 输入通道（如 TI1 或 TI2）接收外部信号作为时钟源。
		- 外部时钟模式 2（External Clock Mode 2）：通过 ETR（External Trigger Input）引脚接收外部信号作为时钟源。
		- 内部触发时钟（Internal Trigger Clock）：由其他定时器的输出触发信号（如 TRGO）提供。
		- 外部晶振（External Oscillator）：通过外部晶振或其他外部时钟源提供。
	- 向上计数（加），向下计数（减），向上/向下（先加后减）
	- 输入捕获
		- 测量 PWM 输入信号的频率及占空比
	- 输出比较
		- PWM生成
- 高级定时器
	- 可编程死区互补输出
	- 重复计数器
	- 带刹车(断路)功能	

## 功能介绍
- 输入捕获
	- 流程：输入通道 滤波和边缘检测  --> 捕获通道 捕获寄存器 产生CCxI中断
	- 一个输入通道的信号可以同时输入给两个捕获通道
		- 目的，配合从模式控制器，做wpm占空比计算
		- 比如输入通道 TI1 的信号经过滤波边沿检测器之后的 TI1FP1 和 TI1FP2 可以进入到捕获通道 IC1 和 IC2
	- 输入通道
		- 目的：滤波和边缘检测
		- 有 4 个 **TIMx_CH1/2/3/4 或 TI1/2/3/4**
		- 把被检测信号输入到这4个通道中进行捕获
		- 当输入的信号存在高频干扰时，可以使用输入滤波器进行滤波
		- 边沿检测器是用来设置信号在捕获时哪种边沿有效
	- 捕获通道
		- 目的，用来捕获输入信号
		- 有4个 IC1/2/3/4
		- 每个捕获通道都有对应的**捕获寄存器TIMx_CCR1/2/3/4**	
- 输出比较
	- 基本原理
		- **定时器的计数器（CNT）与 捕获/比较寄存器（CCR）的值进行比较**。
		- 当计数器值等于 CCR 的值时，产生一个输出比较事件。
		- 输出比较事件可以：
			- 触发中断。
			- 生成 DMA 请求。
			- 改变定时器通道的输出信号状态（如置高、置低、翻转等）。	
	- 用途	
		- 生成 PWM 信号。
		- 产生精确的时间延迟。
		- 控制外设的输出信号。	
	- 输出比较模式
		- 冻结模式（Frozen）：输出保持不变。
		- 主动置高（Set Active）：输出在比较匹配时置高。
		- 主动置低（Set Inactive）：输出在比较匹配时置低。
		- 翻转（Toggle）：输出在比较匹配时翻转。
		- 强制置高（Force Active）：输出强制置高。
		- 强制置低（Force Inactive）：输出强制置低。
		- PWM 模式 1：在计数器小于 CCR 时输出为高，否则为低。
		- PWM 模式 2：在计数器小于 CCR 时输出为低，否则为高。
