# 存储器映射
## 概述
- Memory Mapping
- 将物理存储器（如Flash、RAM、外设等）分配逻辑地址的过程
- **其核心是建立逻辑地址与物理地址的对应关系**
- 将4GB地址空间划分为8个块（Block），每块512MB
- 存储器映射 和 寄存器映射
	- **寄存器映射是存储器映射的子集**
	- **存储器映射是 “大框架”**
		- 它将 CPU 的 4GB 地址空间划分为 “存储区”“外设区” 等区域
	- **寄存器映射是 “小细节”**
		- 它在 “外设区” 内部，给每个外设的寄存器分配具体地址

## 存储器映射
### 地址分配规则​
- **固定映射​**​：由芯片厂商预先定义
- ​**​重映射（Remap）​**​
	- 允许同一资源映射到不同地址，
	- 例如Boot Block可映射到`0x00000000`或Flash尾部，适配不同启动模式

### 作用​​
- ​​统一访问接口​​：CPU通过逻辑地址操作硬件，无需关注物理位置。
- ​​资源隔离​​：不同外设分配独立地址，避免干扰。
- ​​灵活扩展​​：支持外部存储器（如SDRAM）映射到用户空间

## 寄存器映射
### 概述
- Register Mapping
- **是存储器映射的子集**
- 为**外设寄存器**分配逻辑地址并定义别名，使程序通过结构体或宏定义操作寄存器

### 地址计算​​
- ​​总线基地址​​：如APB2总线基地址为0x40000000 + 0x10000 = 0x40010000。
- ​​外设基地址​​：总线基地址 + 偏移量（如GPIOA偏移0x0800，得0x40010800）

### 作用​​
- ​​简化操作​​：通过GPIOA->CRL = 0x00000000替代直接地址操作。
- ​​可读性增强​​：寄存器名（如CRL）直接反映功能。
- ​​跨平台兼容​​：结构体定义适配不同芯片型号
