# 概述
## FreeRTOS概述
- Real Time Operating System
- **嵌入式**领域广泛应用的**实时**操作系统
- 免费开源、轻量、可移植性强、功能丰富受到欢迎
- 面向**微控制器和小型微处理器**的实时操作系统 (RTOS)
- 包括一个内核和一组不断丰富的 IoT 库
- 官网**支持中文**：https://freertos.org/

## 嵌入式开发
- 裸机开发
	- 没有操作系统（OS）或者其他高级软件的支持
	- 直接在裸机硬件上进行软件开发
- 操作系统	
	- 分层
		- 硬件（Hardware）
		- 操作系统（operating system）
		- 应用程序（application programs）
	- 分类
		- **通用**操作系统
			- Linux，Windows，MACOS等
		- **实时**操作系统
			- 常见系统
				- 国外的FreeRTOS、黑莓QNX、μC/OS、RTX 
				- 国内的 RT-Thread、Huawei LiteOS 和 阿里云的AliOS-Things 等
			- 任务必须在给定的时间(Deadline)内完成
				- 对中断和内部异常的处理
				- 对安全相关的事件的处理
				- 任务调度机制等

## FreeRTOS基础知识				
- 多任务处理
- 任务调度
	- 使用**固定优先级**的**抢占式**调度策略
	- 对**同等优先级**的任务执行**时间片轮询**调度
- 任务状态
	- 4种状态
		- 运行态
		- 就绪态	
		- 阻塞态，正在等待延时或外部事件
		- 挂起态
			- 类似暂停，调用函数 vTaskSuspend() 进入挂起态
			- 需要调用解挂函数vTaskResume()才可以进入就绪态
	- 3种任务状态列表
		- 就绪列表：`pxReadyTasksLists[x]，其中x代表任务优先级数值`
		- 阻塞列表：pxDelayedTaskList
		- 挂起列表：xSuspendedTaskList
- 滴答
	- 实时内核通过滴答计数变量测量时间		
	- 每次滴答数增加时，实时内核必须检查是否现在是解除阻塞或唤醒任务的时间
- 上下文切换
- 空闲任务
	- 启动时，自动创建空闲任务，以确保始终存在一个能够运行的任务
	- 以最低优先级创建
	- 负责释放被删除的任务的内存
