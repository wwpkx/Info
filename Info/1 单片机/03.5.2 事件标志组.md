# 事件标志组
## 概念
- 是一种任务间同步机制，允许任务通过设置或等待特定位来实现事件通知。

## 特点
- 位操作：  
	- 事件标志组是一个 **32位** 的变量，每一位可以表示一个独立的事件。
- 多任务同步：  
	- 多个任务可以等待同一个事件标志组中的不同事件。
- 阻塞等待：  
	- 任务可以阻塞等待一个或多个事件位被设置。
- 线程安全：  
	- FreeRTOS 内部保证事件标志组的线程安全。

## 常用 API
- xEventGroupCreate
- xEventGroupGetBits
	- xEventGroupSetBits/xEventGroupSetBitsFromISR
	- EventGroupClearBits
- xEventGroupWaitBits
