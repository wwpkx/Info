# 开发环境
## 概述
- **硬件**（开发板），**核心板**和**扩展版**
- 软件
	- 代码编辑
		- **Keil**
			- 运行在Windows系统
			- 提供了代码编辑、代码编译、仿真和调试
	- 代码编译，**Keil C51 Compiler**
		- 专门用于 51 单片机的 C 语言编译器
		- 基于 ANSI C（C89/C90）标准
	- 程序烧录，**STC-ISP**
		- 是STC公司专门为STC芯片提供的程序烧录工具，用于将程序写入单片机

## Keil
- Keil 需要破解
- 创建项目
	- 选择单片型号
		- **向Keil添加STC89C52系列芯片信息**
		- STC-ISP软件，选中芯片型号，keil仿真设置，添加型号和头文件到keil中
	- 自动提示添加**启动文件**
		- 作用：每次复位都会做清理工作
	- 修改字符集，以支持中文注释
		- edit→ configuration
- 修改编译器配置
	- 工具项目构建和配置，Output，勾选Create Hex File

## STC-ISP
- 烧录程序
	- 将开发板通过数据线与PC相连
	- 选择芯片型号及串口
		- COM的编号可能有所不同
		- 只要保证选择了USB-SERIAL CH340即可
		- 如果扫描不到串口
			- 计算机缺少CH340串口转USB驱动
			- 安装 CH341SER.EXE
	- 打开程序文件，.hex格式
	- 可以查看文件内容和汇编
	- **6T模式/双倍模式**
		- 程序运行速度快了1倍
		- 比如原来1秒闪烁一次的灯，现在半秒闪烁一次
	- 下载程序到单片机，点击 下载/编程
- 软件延时计算
	- 选择 系统频率 和 定时时长
	- 原理
		- 查看生成代码的汇编
		- 根据每个指令的时长 可以计算出 总时长
		- 指令执行时长，可以查看手册，机器周期/时钟周期

## vscode
- Keil体验不好
	- 没有变量提示、不会自动补全括号
	- 没有快速注释
- EIDE（Embedded IDE）插件
	- 概述
		- **提供单片机开发环境**
		- 在VSCode中实现单片机的开发、编译以及烧录
	- 配置
		- **使用Keil的C51 Compiler作为编译器**
			- 为EIDE指定Keil的安装路径，`c:/app/Keil_v5/UV4/UV4.exe`
		- 设置Include Path
			- 选择STC头文件所在目录, `c:/app/Keil_v5/C51/INC/STC`
		- 设置烧录
			- 如果有多个串口时，可以写死 port 实现
			- 烧录配置，烧录命令，`python ./tools/stcflashpy -p $(port) $(hexfile}`
			- `./tools/stcflashpy` 
				- 已经包含在项目目录下
				- 会默认找第一个prot
		- 配置模板
			- 可以使用模板创建工程
			- 比如头文件引用，常用函数等
	- 创建项目
		- 选择空项目，8位MCU项目，8051项目（with Keil C51 compiler）
	- 编译结果，在 **build\Relase** 目录中
	- 使用 vscode 或 STC-ISP 烧录
