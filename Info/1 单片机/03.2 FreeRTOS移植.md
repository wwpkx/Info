# FreeRTOS
## 命名规范
- 变量
	- 使用驼峰式大小写
	- 类型变量为前缀
	- 非 stdint 类型的变量以 x 为前缀
	- 枚举变量以 e 为前缀
- 函数
	- 文件作用域静态（私有）函数以 prv 为前缀
	- API 函数
		- 以其**返回类型为前缀**，并为 void 添加前缀 v
		- 以定义 API 函数文件的名称开头
- 宏
	- configUSE_PREEMPTION

## 源码
- 官网地址：[https://www.freertos.org/](https://www.freertos.org/)
- Github地址：[https://github.com/FreeRTOS/FreeRTOS/releases](https://github.com/FreeRTOS/FreeRTOS/releases)

## 移植
- `Source/*.c`
- `Source/include`
- `Source/portable/RVDS`, 寻找自己的芯片
- `Source/portable/MemMang`
- `FreeRTOSConfig.h`
	- 使用宏判断哪些包含哪些功能
- `stm32f1xx_it.c`
	- 引入 FreeRTOS 相关头文件
	- 注释掉2个中断相关的函数
	- 添加SysTick时钟中断服务函数
		- SysTick 的优先级会设置为15
		- 所以hal中的时钟最好换一个timer，并将优先级设置为1
		- 原因
			- 中断中调用delay时，delay的优先级为15
			- `delay = delay调用时间 + 中断的个数所用时间 - 当前时间`
			- 无法打断当前中断
			- 当前中断又无法执行，导致卡死
