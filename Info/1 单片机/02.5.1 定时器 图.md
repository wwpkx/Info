# 基本计时器与通用计时器的区别

| **特性​**​      | ​**​基本计时器（TIM6、TIM7）​**​ | ​**​通用计时器（TIM2-TIM5、TIM9-TIM14）​**​ |
| ------------- | ------------------------ | ----------------------------------- |
| ​**​核心功能​**​  | 仅支持基础定时（周期性中断、触发外设）      | 继承基本功能，扩展输入捕获、输出比较、PWM生成等           |
| ​**​计数器位数​**​ | 16位（仅递增）                 | 16位/32位（支持递增/递减/中心对齐）               |
| ​**​高级特性​**​  | 无                        | 输入捕获、输出比较、PWM生成、单脉冲模式、同步功能          |
| ​**​应用场景​**​  | 简单定时（延时、周期性任务）、触发DAC/ADC | PWM电机控制、频率测量、编码器信号处理、LED调光          |
| ​**​通道数量​**​  | 0个（无输入/输出通道）             | 1~4个独立通道（支持输入/输出功能）                 |
