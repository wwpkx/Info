# 中断
## 介绍
- Cortex-M3内核
	- 支持256个中断
	- **16个内核中断（也叫做 内部中断或者异常）** 
	- 240个外部中断
		- 每一个外部中断都可以被使能或者禁止
		- 并且可以被设置为 **挂起状态** 或者 **清除状态**
	- 并且具有256级的可编程中断设置
- **芯片厂商会对Cortex-M3的中断进行裁剪**
## 中断来源
- 内核
- 片上外设
- 片外外设，统一由EXTI管理
## 中断体系架构
- NVIC
	- Nested vectored interrupt controller嵌套向量中断控制器
	- 和处理器核的接口紧密相连
	- **管理所有中断**
	- 中断优先级
		- NVIC用4个位来控制优先级，值小的优先级高
		- 对优先级**分了5组**，在程序中先对中断进行分组
		- 分为
			- 抢占优先级，高优先级抢占低优先级
			- 响应优先级，**同时到来 或者 等待处理** 时，优先相应高优先级的
- EXTI，20个外部中断
	- 16个IO的中断与PVD(电源电压检测)
	- RTC(实时时钟)
	- USB
	- 以太网检测
